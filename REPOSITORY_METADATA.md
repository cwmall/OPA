## Recommended repository settings

- Enable Issues and Discussions.
- Enable the dependency graph and Dependabot security alerts.
- Require pull requests before merging into the default branch.
- Require at least one approving review for protected branches.
- Dismiss stale approvals when new commits are pushed.
- Block force pushes and branch deletion on the default branch.
- Enable secret scanning when available.
- Use squash merging to keep the default-branch history focused.

No homepage URL, repository owner, GitHub usernames, or release date has been assumed. Add those fields only after they are confirmed.
