# SPICE kernels

Place the SPICE kernels distributed with OPA in this directory. Kernel files are intentionally tracked by Git rather than excluded by `.gitignore`.

For every kernel:

1. confirm that redistribution is permitted;
2. record the source, coverage, retrieval date, checksum, terms, and purpose in `../DATA_PROVENANCE.md`;
3. preserve the original filename and notices where required; and
4. use repository-relative paths in the application.

Kernel files remain subject to their original terms and are not automatically covered by OPA's Apache License 2.0.
