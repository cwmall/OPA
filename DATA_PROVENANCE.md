## Assets

The public mark `assets/opa_public_mark.svg` and Retro control SVGs are original repository-native geometry. The application owner selected the established generic OPA emblem and mission-banner raster artwork for the product identity; these files contain no operator name or embedded text metadata. Their original authorship and redistribution grant have not yet been independently verified, so they remain part of the manual ownership/licensing gate below.

## Python dependencies

Versions are pinned in `requirements.txt`. Review their upstream licenses before binary redistribution. In particular, Riverbank states that PyQt6 is dual-licensed under GPLv3 and a commercial license; PyQt6 is not LGPL. The project owner must choose a compatible application license or obtain a commercial PyQt6 license before publication.

## Unresolved legal decision

No verified project-level copyright/license grant existed in the supplied workspace. Consequently no `LICENSE` file was created. Selecting a license and confirming code ownership is a release blocker, not a technical default.
